Dynamic analysis findings

Each finding below pairs the sandbox's raw observation with a plain-language reference annotation. Filled citation numbers link to official vendor or standards documentation; outlined numbers link to community-maintained, unofficial references — weigh them accordingly.

Windows loader

sha256 c1a9e3f2 5b7d0468 9f2e1c3a 6b8d4f70 a2c9e5b1 3d7f0468 9c2a6e1d 4b8f3706

Detonated in Any.Run3. Behavior and family attribution match publicly documented Emotet loader campaigns6.

  • Allocates memory in explorer.exe via VirtualAllocEx7, writes shellcode with WriteProcessMemory8, and starts execution with CreateRemoteThread9 — a documented, if frequently abused, process-injection sequence.
  • Separately calls NtMapViewOfSection10 directly against ntdll rather than going through the documented Win32 path — a native-API call Microsoft does not publish, and a common evasion technique for tooling that only watches Win32 calls.
  • Drops and loads RTCore64.sys, a legitimately signed MSI Afterburner driver with a publicly known kernel read/write vulnerability11, then uses it to load an unsigned kernel module.
  • That kernel module unlinks the loader's own process by rewriting the ActiveProcessLinks pointer inside the _EPROCESS structure12 — a reverse-engineered, build-specific structure layout, not something Microsoft documents publicly.

Linux ELF backdoor

sha256 7e2b9d4a 1f6c8305 b3a7e1d9 4c6f2a80 e9d3b5c1 7a0f4e28 6d1c9b3a 5e8f0472

Detonated in HybridAnalysis13 after being retrieved from the same address on port 8080/tcp.

  • Beacons outbound to 198.51.100.23 on port 4444/tcp on a five-minute interval.
  • Drops diamorphine.ko into /lib/modules/ and loads it to hook the syscall table, hiding its own process from ps, ls, and /proc listings. no reference found — this is not a standard distribution kernel module; the name matches a publicly known open-source rootkit proof-of-concept rather than anything with official documentation, which is itself informative.
  • Links against libpcap.so.1.10.314 to sniff unencrypted credentials from the local network segment — a legitimate, widely-used packet-capture library; its presence here is context for how the credential theft works, not evidence on its own.
